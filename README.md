# Night Expressway — 夜間走行

深夜の都市高速を走り続ける、眺めるためのドライブシミュレーター。
都市高架・トンネル・湾岸橋を自動生成し、街の灯り、雨、走行音、生成ラジオでリラックスできる時間を作る。

公開ページ: https://nu424.github.io/night-expressway/

## 操作

| 操作 | 動作 |
|---|---|
| Tab | 設定画面（ヘッドユニット）を開閉 |
| ドラッグ | 車内を見回す。離して数秒で正面へ戻る |
| V | 視点（運転席 → 助手席 → 助手席の窓 → ダッシュカム） |
| R | 天気（自動 → 晴れ → 雨） |
| N | ラジオの次の曲 |
| F | 全画面 |
| M | ミュート |
| B / P | 俯瞰デバッグ / 計測表示 |

## 設定画面

Tab で開く。値は動かした瞬間に反映され、このブラウザに自動保存される。

| タブ | 内容 |
|---|---|
| 走行 | 巡航速度、交通量、追い越し、視点、頭の揺れ、メーターの色、車内を流れる光 |
| 映像 | 露出、目の慣れ、にじみ、光芒、霞、粒状感、周辺減光、色温度、彩度、画質 |
| 街 | 窓の点灯率と明るさ、街灯の色、灯火の照り返し |
| 天気 | 天気、雨量、水滴、ワイパー、移り変わる速さ |
| ラジオ | 局、音量、テンポ、音色、音数、ドラム、テープの質感、トンネルでの減衰 |
| 環境音 | ロードノイズ、風、継ぎ目、雨、車内のこもり、動力（ガソリン・ハイブリッド・EV） |
| 旅 | ルートの好み、夜明けへの時間の流れ、スリープタイマー |
| 保存 | プリセット（標準・深夜2時・雨の湾岸・トンネル・シネマ・眠りへ・軽量）、自作プリセット、URL共有、リセット |

## 開発

```
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェック
npm test           # 純ロジックのテスト
npm run build      # dist/ へ出力
```

`main` に push すると GitHub Actions がビルドし、GitHub Pages に公開する。

### 検証用スクリプト（ビルド後に実行）

| コマンド | 内容 |
|---|---|
| `npm run shots` | 定点撮影。同じシード・フレーム数で6シーンを `shots/current/` に出力 |
| `node scripts/shots.mjs --only traffic,sweep0,dawn,side` | 追加シーン（車両、流れる光の連続コマ、夜明け、視点） |
| `node scripts/shots.mjs --legacy` | 分割前の単一HTML版を同条件で撮影 |
| `node scripts/perf.mjs --sec 40` | 実走行のフレーム時間・GPU時間・内部解像度を計測 |
| `node scripts/perf-matrix.mjs --scale 0.7` | 要素を1つずつ無効にして負荷を切り分ける |
| `node scripts/audio-check.mjs` | 各局と環境音を書き出し、音量・ピーク・帯域の偏りを数値で確認 |
| `node scripts/ui-shot.mjs RADIO,VIEW` | 設定画面を開いて撮影し、全プリセットの適用を試す |

計測値は同じ実行の中でだけ比べること。ヘッドレス実行のフレームレートは、PCの状態によって日をまたがずとも変わる。

### URLパラメータ

| パラメータ | 意味 |
|---|---|
| `seed=7` | 乱数の種。同じ値なら同じ道と街になる |
| `frames=200` | 実時間ループを使わず、指定フレームだけ進めて止める（撮影用。保存済みの設定は読まず、解像度も固定） |
| `skip=3300` | 指定距離(m)から開始 |
| `rain` / `clean` / `debug` / `perf` | 雨・ダッシュカム視点・俯瞰・計測表示で開始 |
| `p=...` | 共有された設定値（設定画面の「URLをコピー」で作る） |

## 構成

```
src/
  main.ts        起動とメインループ
  core/          乱数・定数・状態・設定レジストリ
  world/         道路線形、区間、チャンク生成、ベイク照明、建物、照明の列挙、空と地面
  traffic/       交通流（IDM）と車両描画
  car/           車内（メーター、流れる光）、カメラ（座席・見回し）
  weather/       天気遷移、雨、フロントガラスの水滴とワイパー
  render/        レンダラー、描画パイプライン、平面反射、自動解像度調整
  audio/         環境音、生成ラジオ
  ui/            スタート画面、操作、設定項目の定義、ヘッドユニット
  shaders/       GLSL
  debug/         俯瞰ビュー、計測
legacy/          分割前の単一HTML版（比較用）
docs/PLAN.md     改善計画書と進捗記録
```

設定項目を増やすときは `src/ui/params.ts` に1行足す。保存・プリセット・リセット・URL共有・設定画面への表示は自動で付く。
