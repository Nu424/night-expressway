# Night Expressway 改善計画書

作成日: 2026-11-19
対象: `night-expressway-simulator.html`（単一HTML・約1,900行・120KB）

---

## 1. 目的とゴール

深夜の高速ドライブの「リラックスした・チルな雰囲気」を、次の3段階で高める。

1. **雰囲気を高める**: 没入を壊す要素（チラつき、カクつき、作り物感）を取り除く。
2. **リアルに再現する**: 光・音・車内・交通の質を、実際の夜間走行の記憶に近づける。
3. **リアルを超える**: 現実のドライブにはない快適さ（生成ラジオ、助手席視点、旅の弧、眠りへの導入）を加える。

### 体験の設計原則

| 原則 | 意味 |
|---|---|
| 引き算が先 | 新要素を足す前に、目と耳に引っかかるノイズを消す。 |
| リズムが核 | 街灯の光、継ぎ目音、テールランプ、音楽のテンポを揃え、反復で落ち着かせる。 |
| 車内は繭 | 外は流れ、内は静か。車内の質感と暗さが安心感を作る。 |
| 操作は任意 | 何もしなくても成立する。触りたい人だけが設定を触れる。 |
| 急な変化を作らない | 天気・区間・音量・露出はすべて数秒〜数十秒かけて遷移させる。 |

### 決定済みの前提

- 音楽は**生成型**（Web Audio による合成）で作る。音源ファイルは持たない。
- コードは**分割**し、**GitHub Pages** で公開する。
- 映像・音声のパラメータを**設定画面**から調整できるようにする。プリセットとリセットを備える。

## 2. 現状の評価

### 強み（残すもの）

- 区間（都市高架・トンネル・湾岸橋）を無限に自動生成する道路システム
- 頂点ベイクによる街灯・トンネル照明
- 濡れ路面と水面の平面反射
- IDM（車間追従モデル）による交通流と自動車線変更
- 継ぎ目の2連打音、トンネル残響、追い越し音
- `?seed` `?frames` `?skip` による決定的な再現（検証に使える）

### 弱み（直すもの）

| 分類 | 問題 | 根拠 |
|---|---|---|
| 車内 | 黒い板の枠に見える。ハンドル・メーター・ボンネットがない。 | 静止画で確認 |
| 車内 | メーター照り返しのメッシュ `gl` が作成後にシーンへ追加されていない。 | コードで確認 |
| 光 | 街灯の光だまりが路面に見えず、車内を流れる光もない。灯具にハロがない。 | 静止画で確認 |
| 街 | 近景ビルの窓が大きく白飛びし、点灯率が高い。高欄が茶色い板に見える。 | 静止画で確認 |
| 街 | 反射板が四角い光の塊になっている。 | 静止画で確認 |
| 雨 | 路面反射がモザイク状。水滴が泡状。ワイパーが細線2本。 | 静止画で確認 |
| 車両 | 箱型で、テールランプの路面照り返しがない。 | 静止画・コードで確認 |
| 音 | 音楽がない。全音源がノイズ合成で、エンジンはノコギリ波。 | コードで確認 |
| 描画 | アンチエイリアス無効。走行中のチラつきが想定される。 | コードで確認（動画は未確認） |
| 性能 | チャンク生成を1フレームで行うため、約5秒周期の引っかかりが疑われる。 | コードからの推定（未計測） |
| 構造 | 単一ファイルに全機能があり、調整値がコード内に散在している。 | コードで確認 |

**検証上の制約**: 開発側は静止画の撮影と数値計測はできるが、動画と音を直接は体験できない。動きと音の最終判断は、各フェーズ末の試走で確認してもらう。

## 3. 技術方針

### 3.1 スタック

| 項目 | 採用 | 理由 |
|---|---|---|
| ビルド | Vite | 設定が少なく、開発サーバーの更新が速い。静的出力がそのまま Pages に載る。 |
| 言語 | TypeScript | 2,000行の移植と以後の拡張で、型が取り違えを防ぐ。 |
| 描画 | three.js（npm、バージョン固定） | 現行資産をそのまま移せる。 |
| UIフレームワーク | なし | 設定画面は世界観に合わせた独自UIにするため、素のDOMとCSSで足りる。 |
| シェーダ | `.glsl` を文字列として読み込み | 現在の埋め込み文字列を分離し、差分を追いやすくする。 |
| テスト | Vitest（純ロジックのみ） | 道路生成・IDM・設定の保存復元など、描画に依らない部分を守る。 |
| 画面検証 | Playwright による定点撮影 | 現行の `?seed&frames&skip` を引き継ぎ、変更前後の静止画を比べる。 |
| 公開 | GitHub Actions → GitHub Pages | `main` への push で自動ビルド・公開する。 |

### 3.3 設定レジストリ（全フェーズの土台）

調整可能な値を1か所に登録し、UI・保存・プリセット・リセットを同じ定義から生成する。

```ts
defineParam({
  id: 'post.bloom.strength',
  label: 'にじみ', group: '映像/レンズ',
  type: 'range', min: 0, max: 1.5, step: 0.01, default: 0.55,
  apply: v => bloomPass.strength = v,
});
```

- 型は `range` / `toggle` / `select` / `color` の4種。
- 値は `localStorage` に保存する。保存データには版番号を付け、項目の増減に耐える。
- プリセットは「id→値」の差分。組み込みプリセットとユーザー保存プリセットを持つ。
- リセットは「項目単位」「グループ単位」「全体」の3段階。
- 現在の設定をURLに書き出して共有できる（`?p=...`）。
- 以後の施策は、追加した調整値を必ずここへ登録する。

### 3.4 GitHub Pages

- `vite.config.ts` の `base` を相対パス（`./`）にし、リポジトリ名に依存させない。
- `deploy.yml`: `npm ci` → `npm run build` → `actions/deploy-pages`。
- フォントは当面 Google Fonts を使う。オフライン動作が必要になれば同梱に切り替える。

## 4. 設定UI「ヘッドユニット」

設定は、センターコンソールのカーナビ／オーディオ画面として表示する。

- **開閉**: `Tab` または画面下端のホバーで、ダッシュボードから画面がせり上がる。開いている間も走行は続く。
- **見た目**: 暗い液晶、琥珀または青緑の単色表示、細い罫線、等幅数字。車内照明と同じ色を使い、外光で画面がわずかに照らされる。
- **操作音**: ボタンとノブに小さなクリック音を付ける（オフにできる）。
- **調整は即時反映**: つまみを動かした瞬間に映像と音が変わる。

### タブ構成

| タブ | 主な項目 |
|---|---|
| DRIVE（走行） | 巡航速度、交通量、車線変更の頻度、視点（運転席・助手席・サイド・ダッシュカム）、頭の揺れ |
| VIEW（映像） | 露出、にじみ、光条、粒状感、周辺減光、色温度、彩度、モーションブラー、霞の濃さ、画質 |
| CITY（街） | 窓の点灯率、ネオンの量、街灯の色（ナトリウム・電球色・白）、街灯の間隔 |
| WEATHER（天気） | 自動／固定、雨量、路面の濡れ、水滴の量、ワイパー速度、遷移の速さ |
| RADIO（ラジオ） | 局、音楽音量、テンポ、明るさ、音数、ドラムの有無、継ぎ目同期、トンネルでの減衰 |
| SOUND（環境音） | ロードノイズ、風、エンジン（ガソリン・ハイブリッド・EV）、雨音、継ぎ目、ウインカー、車内こもり |
| TRIP（旅） | 時刻の進み方（固定・実時刻・早回し）、スリープタイマー、ルートの好み（都市・トンネル・湾岸の比率） |
| MEMORY（保存） | プリセット呼び出し・保存、リセット、URL共有 |

### 組み込みプリセット（案）

| 名前 | 内容 |
|---|---|
| 標準 | 既定値。晴れ、ナトリウム灯多め、ラジオ控えめ。 |
| 深夜2時 | 交通量少、窓の点灯率低、アンビエント局、露出やや暗め。 |
| 雨の湾岸 | 雨固定、湾岸比率高、白色灯、水滴多め。 |
| トンネル | トンネル比率高、反響強め、ローファイ局。 |
| シネマ | 光条・粒状感・周辺減光強め、助手席視点。 |
| 眠りへ | 速度低め、音楽ゆっくり、60分でフェードアウト、画面を徐々に暗く。 |
| 軽量 | 反射・ミラー・ブラーを切り、解像度を下げる。 |

## 5. 生成ラジオの設計

### 5.1 構成

```
作曲層（シード付き乱数）
  調・テンポ・コード進行・構成（A/B/間奏）を数小節先まで決める
      ↓
演奏層（先読みスケジューラ、約0.2秒先まで予約）
  楽器ごとに音符を Web Audio の時刻で発音
      ↓
楽器バス → マスター処理 → カーオーディオ処理 → 車内ミックス
```

### 5.2 楽器（すべて合成）

| 楽器 | 方式 |
|---|---|
| エレクトリックピアノ | 2オペレータFM＋トレモロ。ベロシティで倍音量を変える。 |
| パッド | デチューンした複数オシレータ＋ゆっくり動くローパス。 |
| ベース | サイン＋軽い倍音、短いグライド。 |
| ドラム | キック（ピッチ下降サイン）、スネア（ノイズ＋胴鳴り）、ハット（高域ノイズ）。スウィングと微小な揺らぎ。 |
| 装飾 | ベル、ギター風のプラック、遠いサックス風リード（低頻度）。 |
| 質感 | テープの揺れ（ごく浅いピッチ変動）、ヒスノイズ、レコードの小さなパチ音（局による）。 |

### 5.3 局（案）

| 局 | 性格 | テンポ |
|---|---|---|
| 深夜便 Ambient | ドラムなし。パッドと疎らなピアノ。 | 自由〜60 |
| Lo-Fi | エレピ、緩いドラム、テープ質感。 | 68〜80 |
| Night Groove | 明るい7thコード、動くベース、軽快なドラム。 | 92〜108 |
| Jazz Trio 風 | ピアノ・ウォーキングベース・ブラシ。 | 80〜120（スウィング） |
| OFF | 音楽なし。走行音のみ。 |  |

- 和声は、メジャー7th・マイナー9thを中心とした循環進行を、確率表から生成する。
- 曲は3〜5分で次の曲へ移る。曲間は短い無音か局のジングル（合成音）でつなぐ。
- 表示部に局名と曲名（生成した架空の曲名）を出す。

### 5.4 車内での鳴り方

- **カーオーディオ処理**: 小型スピーカーを模した帯域制限、短い車内残響、ドアスピーカー位置を模した左右差。
- **走行音との混ざり**: 速度が上がるとロードノイズが音楽の低域を覆う。音楽側は自動で少し持ち上げる（調整可）。
- **トンネル**: 受信が弱まる演出として、高域が落ち、ノイズが混じる。強さは設定で変えられ、切ることもできる。
- **継ぎ目同期（任意）**: 継ぎ目の間隔（40m）と速度からテンポを割り出し、音楽の拍を継ぎ目音に寄せる。現実にはない「道路と音楽が合う」体験を狙う。

### 5.5 音の検証方法

- `OfflineAudioContext` で各局を書き出し、音量（ラウドネス）・クリップの有無・帯域分布を数値で確認する。
- 聴感の良し悪しは試聴で判断してもらう。調整しやすいよう、主要な値は RADIO タブに出す。

#### 計画から変えた点

- 描画パイプラインを自前に作り直した。EffectComposer の全画面パスの重なりが、内蔵GPUでの負荷の大半だったため。
- 車内は別シーンではなく、カメラの子として車外と同じ描画で描く。描画呼び出しを2回に分けると、内蔵GPUでは内容に関係なく約6ms余計にかかった。
- 車内の照度は頂点で計算する（画素ごとの計算は内蔵GPUに重い）。
- チャンク生成の時分割（1-2）は見送った。計測では最大9ms程度で、引っかかりの主因ではなかった。
- モーションブラーと横方向の光条（2-7の一部）は、負荷を考えて見送った。
